## 審査の 前に 確かめる こと
- **ガチャの 確率**: Apple の 審査ガイドライン 3.1.1 は、ランダムに 中身が 決まる 有料アイテム(ガチャ)に ついて、買う 前に 種類ごとの 確率を 見せる ことを 求めている。いまは ガチャ画面 →「確率・くわしく」に レア度ごとの 確率・同じ レア度内は 等確率・天井・10連 +1 の 中身が 出る。**石を 買う 画面(ショップ)から 1タップで 確率に 行ける 導線**が あるかを 実機で 確かめる。
- **卵の 色の 昇格演出**: 確率は 変わらない 見た目だけの 演出、と 確率画面に 書いて ある。説明文でも 誤解させない。
- **年齢区分**: App Store Connect の 年齢区分の 質問に 答える(2026年に 質問が 増えて いる。ガチャ・広告・ユーザー同士の やりとり(コードの 共有、Game Center の 対戦)に 当たる 項目を 正直に)。結果の 年齢は 質問の 答えで 決まるので ここでは 決め打ちしない。
- **課金の 商品登録**: README の 一覧(パス・パック・石 3種・きずなの証 など)を App Store Connect に 登録。価格は ゲーム内の 表示と 同じに。
- **復元ボタン**: ショップの 下に ある(非消耗型の 復元)。
- **利用規約・プライバシーポリシー**: `WebGameView.swift` の URL が まだ 仮(example.com)。本物の ページを 用意して 差しかえる。広告(AdMob)を 入れるなら プライバシーの 申告(トラッキング・データ収集)も。
- **Game Center / iCloud**: 使うなら 説明文と 申告に 入れる。使わない 版で 先に 出すなら バトルタブの 2ページ目を かくす(言って くれれば 1行で 切れる ように する)。
- **テスト版の 表示**: ショップの「テスト版。請求は発生しない」と タイトルの「TEST BUILD」は アプリ版では 出ない ことを 確かめる。
