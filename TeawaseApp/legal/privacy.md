# テアワセ！ プライバシーポリシー(下書き)
**これは Claude が 書いた 下書き。広告 SDK(AdMob など)を 入れるか どうかで 中身が 変わる。法律と App Store の 申告(App Privacy)との 一致を Koshin が 確認する こと。**

制定日: 2026年__月__日 / 運営者: ____ / 連絡先: ____

## 1. 集める 情報
| 情報 | 何に 使うか | どこに ある か |
|---|---|---|
| ゲームの 進み(なかま・アイテム・設定) | ゲームを 続ける ため | 端末の 中だけ |
| 購入の 記録 | 買った ものを わたす・復元する ため | Apple(運営者は カードなどの 情報を 受け取らない) |
| 「みんなで 大ボス」の けずった 量と 日付 | みんなの 合計を 出す ため | Apple の iCloud(公開データベース)。名前は 入れず、iCloud の 利用者ごとの ID(運営者には だれか わからない 文字列)で 分ける |
| 「いっしょに でかける」の やりとり | 2人で あそぶ ため | Apple の Game Center を 通して 相手の 端末へ。運営者は 保存しない |
| 広告の ための 情報(広告を 入れる 場合) | 広告を 出す ため | 広告を 配る 会社(例: Google AdMob)。その 会社の ポリシーに したがう |

## 2. 第三者への 提供
法律で 決まって いる 場合を のぞき、上の 表に ない 形で 第三者に わたす ことは ありません。

## 3. トラッキング
(広告を 入れて 端末を またいで 追う 場合)iOS の「App Tracking Transparency」で 許可を とってから に します。許可しなくても ゲームは 遊べます。
(広告を 入れない / 追わない 場合は この 節を 消し、App Store の 申告も「トラッキング なし」に する)

## 4. 子どもの 利用
本アプリは 子どもも 遊べる 内容ですが、13歳未満の 子どもから 意図して 個人情報を 集める ことは しません。

## 5. 消す・問い合わせ
- 端末の 中の データは アプリを 消すと 消えます。
- 大ボスの 記録を 消して ほしい 時は 連絡先へ。

## 6. 変更
この ポリシーは 変わる ことが あります。変わった 時は アプリか 配信ページで お知らせします。
