# テアワセ！ 音の 発注リスト
いまの 音は ぜんぶ その場で 合成した 電子音。下の 名前の **mp3** を `Teawase/Resources/a/snd/`(ゲームでは `a/snd/`)に 置くと、その 音だけ 合成音の かわりに 鳴る。置いて いない 音は 今までどおり。1つずつ 入れて いける。

共通: mp3・44.1kHz・ステレオ(SE は モノラルで 可)。SE は 頭の 無音を 切る。音量は そろえる(SE は -3dB くらいの 山、BGM は SE より 小さめ)。スマホの スピーカーは 低音が 出ないので、低い 音だけの SE は さける。

## まだ ファイルに できない 音(合成の まま)
必殺ムービーの 音(動画に 入って いる)/ 数字が かけ上がる 音 / ★5以上の 相手の 曲。必要に なったら 名前を 足す。

## 入れた あとの 確かめ方
アプリ(か ブラウザ)で 音を 出して、その 場面を 1回 通す。音が 大きすぎ・小さすぎなら `index.html` の `sndPlay("名前",音量)` と `BGMVOL` で 調整する(言って くれれば こちらで 直す)。
